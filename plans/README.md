# Plans

Plan files you can import into openGym: in the app, **Plan → share icon (top right) → Import a
plan file**. Then switch on **Use this weekly schedule**, which is **off** by default, and tap
**Add to my plan**.

To get a file onto the iPhone: open it on GitHub in Safari → **⋯ → Download** (or the download
icon). It lands in Files → Downloads.

## calisthenics-ppl.opengym-plan.json

Muscle-building calisthenics for an intermediate, using only a pull-up bar, the floor and household
items (chair, step, wall, towel). Push / Pull / Legs twice a week, about 60 minutes per session.

| Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|---|---|---|---|---|---|---|
| Push A · Chest | Pull A · Lats | Legs A · Quads | Push B · Shoulders | Pull B · Upper back | Legs B · Posterior | Rest |

**How it progresses (the app does this automatically):** each exercise starts at the listed reps.
Every session where you finish all sets cleanly, the target goes up by one rep (two for one-side
moves) until it reaches the top of the range. Then the reps drop back and a set is added. At 6 sets
the app tells you to switch to a harder variation, for example decline → archer → pseudo-planche
push-ups, or pull-ups → archer → weighted (backpack). Holds (planche lean, front lever, handstand,
L-sit) gain 5 s each time you hold every set for the full time.

- **One-side moves** (archer, pistol, split squat, lunges, single-leg bridge, calf raises, slider
  curls): log the total for **both sides together**. 16 means 8 per side.
- **Start honestly.** If a starting number is too easy or too hard, edit it in the routine on the
  first day. Aim to finish each set with 1–2 reps left in the tank.
- **Only want 5 days?** Leave Saturday (Legs B) unassigned, or alternate Legs A/B each week.
- **Swaps for missing kit:** dips need two sturdy chairs or a counter corner. Rows need a sturdy
  table or a low bar; otherwise do a towel row around a closed door. Every exercise's note in the
  app says the same.
- The routine screen says "Linear progression … the weight goes up". For bodyweight exercises with
  no weight entered, the app climbs reps and sets instead, as described above.
